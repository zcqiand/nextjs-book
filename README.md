# Next.js 15 全栈开发实战 - 代码示例库

> **本书配套代码示例** — 从章节中提取的完整可运行代码

## 关于本书

在过去的几年里，Web 开发领域发生了巨大的变化。前端框架从最初的 jQuery 时代，经历了 Angular、Vue、React 的崛起，如今 React 已成为构建现代 Web 应用的主流选择。

然而，React 本身只是一个 UI 库。将其转化为生产级应用，需要处理大量额外的工作：服务端渲染、路由管理、代码分割、图片优化、构建工具配置……这些工作不仅耗时，而且需要开发者具备全栈知识。

**Next.js 正是来解决这个问题的。**

Next.js 是基于 React 的全栈 Web 开发框架，它将生产环境所需的各种能力全部打包开箱即用。当你使用 create-next-app 创建一个新项目时，服务端渲染、文件系统路由、代码分割、图片优化——全部都已经配置好了。

这本书将帮助你系统掌握 Next.js 全栈开发能力，从「学这个工具」转向「用这个工具开发」。

## 本书特点

**第一，应用目标驱动。** 每一章开头都明确说明「学完这章你能交付什么」，并且这些目标都是真实的可交付成果——不是「了解配置体系」，而是「能用多层配置管理不同项目的规则」。

**第二，两个完整生产级项目。** 博客系统和电商应用两个端到端项目，覆盖需求分析、数据建模、核心业务、集成测试、部署上线全流程。

**第三，决策引导型内容。** 每章都包含决策框架节，帮助读者理解「在什么场景下选择什么方案」。例如 App Router vs Pages Router 的选择、SSR vs SSG vs ISR 的适用场景、不同状态管理方案的权衡等。

## 谁应该读这本书

本书适合以下读者：

- **具备 HTML/CSS/JavaScript 基础的前端开发者**：你已经有前端基础，想学习如何用 Next.js 构建完整的全栈应用
- **了解 React 基本概念的学习者**：你知道 React 的基本概念，想深入理解 React 生态下的全栈开发
- **希望构建企业级应用的工程师**：你想学习如何用 Next.js 构建生产级别的企业应用
- **技术团队的培训资料**：你的团队正在使用或计划使用 Next.js，需要系统性学习资料

## 如何使用代码

### 环境准备

- **Node.js**: 18.18.0+（推荐使用 LTS 版本）
- **npm**: 9.0+ 或 **pnpm**: 8.0+
- **Next.js**: 15.x
- **React**: 19.x

### 文件命名规范

```text
chapter{章节号:02d}_{描述/类名/函数名}.{扩展名}
```

示例：

- `chapter01_AuthorCard.tsx` - 第1章的作者卡片组件
- `chapter03_layout.tsx` - 第3章的布局组件
- `chapter11_generateStaticParams.tsx` - 第11章的动态路由示例

### 运行示例

**TypeScript/JavaScript 代码**:

```bash
# 安装依赖
npm install

# 运行开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm start
```

**配置文件**: 直接在相应工具中使用
